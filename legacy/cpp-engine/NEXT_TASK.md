## This Session (Text Orientation Fix)

### Root Cause Found
**The V flip in `getGlyphUVs()` was WRONG.** OpenGL's `glTexImage2D` stores the first pixel row of data at the texture BOTTOM (V=0). The font atlas generates pixel data with row 0 at the image TOP. The correct mapping is:
- `vMin = (row * FONT_GLYPH_H) / FONT_TEX_H` (top vertex → start of glyph)
- `vMax = (row * FONT_GLYPH_H + (FONT_GLYPH_H - 1)) / FONT_TEX_H` (bottom vertex → end of glyph)

The previous V flip (`vMin = 1.0 - ratio`) was sampling from the wrong atlas rows, causing upside-down text with random glyph corruption.
